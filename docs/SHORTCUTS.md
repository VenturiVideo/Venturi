# Keyboard shortcuts

These are the default shortcuts. Each one can be changed in **Settings**
(`Ctrl+,`), so the keys you see may differ if you have rebound them.

## Editing the timeline

| Action | Shortcut |
|---|---|
| Split the clip at the playhead (razor) | `T` |
| Delete the selected clips (leaves a gap) | `Delete` or `Backspace` |
| Ripple delete (closes the gap) | `<` (ISO key between left Shift and `Z`) |
| Select tool | `V` |
| Slip tool | `B` |
| Enable or disable the selected clips | `D` |
| Select all clips | `Ctrl+A` |
| Select clips from the playhead onward | `Alt+Y` |
| Open the selected compound clip | `Enter` |
| Leave the compound clip | `Alt+Left` |
| Show retime controls | `Ctrl+R` |
| Add a marker at the playhead | `M` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Shift+Z` |
| Copy / Cut / Paste clips | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| Paste attributes | `Alt+V` |
| Zoom the timeline in / out | `Ctrl+=` / `Ctrl+-` |
| Rename the selected item in the media pool | `F2` |

## Playback and in/out points

| Action | Shortcut |
|---|---|
| Play / pause | `Space` |
| Previous / next frame | `Left` / `Right` |
| Fast playback | `A` |
| Set in point | `I` |
| Set out point | `O` |
| Clear in point | `Alt+I` |
| Clear out point | `Alt+O` |
| Clear in and out points | `Alt+X` |

## Viewer

| Action | Shortcut |
|---|---|
| Fit the frame to the viewer | `Z` |
| Show the frame at 100% | `Alt+Shift+Z` |
| Fullscreen viewer | `Ctrl+F` (`Esc` exits) |

## Project and file

| Action | Shortcut |
|---|---|
| New project | `Ctrl+N` |
| Open project | `Ctrl+O` |
| Save project | `Ctrl+S` |
| Save project as | `Ctrl+Shift+S` |
| Import media | `Ctrl+I` |
| Export | `Ctrl+Shift+E` |
| Settings | `Ctrl+,` |

## Notes

- Shortcuts are ignored while you type in a text field, so typing a title will
  not cut or delete clips.
- `Delete` and `Ctrl+A` act on the panel you last clicked: the keyframe editor,
  the media pool, or the timeline.
- Keys are listed for the US layout unless noted. The `<` key is the one on the
  ISO keyboard between left Shift and `Z`, which is `<` on Italian layouts.
